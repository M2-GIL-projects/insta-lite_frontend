# Insta-lite Backend

Insta-lite est une application de portfolio permettant de partager des images et vidéos. Ce projet vise à fournir une plateforme conviviale pour les utilisateurs souhaitant accéder à du contenu visuel, ainsi qu'un espace d'administration pour gérer ce contenu.

## Installation et exécution

### Prérequis
1. **Docker** : Docker est installé et en cours d'exécution sur votre machine.
2. **Port** : Port 8080 accessible (par défaut 8080 pour le backend

### Démarrage avec Docker Compose
- Lancement par : ```docker-compose up --build```
- Backend accessible: http://localhost:8080

---

## API REST
### Authentification

- POST /auth/login : Authentification des utilisateurs.
- POST /auth/signup : Inscription des utilisateurs.
- POST /auth/logout : Déconnexion des utilisateurs.

### Gestion des utilisateurs

- GET /users/ : Liste des utilisateurs.
- GET /users/me : Utilisateur actif
- PUT /users/{id} : Mise à jour des informations utilisateur.
- DELETE /users/{id} : Suppression d'un utilisateur.

### Gestion des médias

- GET /media : Liste des images et vidéos.
- POST /media : Upload d'une image ou vidéo.
- PUT /media/{id} : Modification d'un média.
- DELETE /media/{id} : Suppression d'un média.

## Structure du projet

- Framework : Spring Boot.
- Sécurité : Spring Security avec JWT.
- Base de données : PostgreSQL.
- Outils vidéo : FFmpeg.

## Fonctionnalités principales
### Public
- Accès au contenu public sans authentification.
- Navigation facile dans les images et vidéos disponibles publiquement.

### Privé (Utilisateurs connectés)
- Accès au contenu privé après authentification.
- Possibilité de commenter les images et vidéos.
- Gestion de profil pour modifier les informations personnelles.

### Administration
- Gestion complète des utilisateurs (CRUD).
- Gestion des images et vidéos (CRUD) avec options public/privé.
- Téléchargement d'images et vidéos.
- Tableau de bord pour les statistiques : volume, format, etc.

### Fonctionnalités expérimentales (optionnelles)
- Édition et optimisation des vidéos (changement de codecs, découpe).
- Incrustation de texte dans les images.
- Mise à jour dynamique du contenu via Websockets.
